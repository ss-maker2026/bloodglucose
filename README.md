# 血糖値記録アプリ

妊娠糖尿病の血糖値測定を、できるだけ短時間で記録するためのシンプルなWebアプリ（Next.js App Router + TypeScript + Tailwind CSS）。

## コンセプト

「アプリを開く → 記録する場所をタップ → 数字を入力 → 保存」を最短で完了できることを最優先にしています。食事内容・カロリー・体重・AIアドバイス・医療判定などの機能は含みません。

## 記録するデータ

- 日付
- 記録タイミング（朝食前 / 朝食後2時間 / 昼食前 / 昼食後2時間 / 夕食前 / 夕食後2時間）
- 血糖値（0〜999 mg/dLの整数）

データはブラウザの `localStorage` にのみ保存されます（サーバー送信・アカウント登録なし）。

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 を開いて確認できます。

## 免責事項

本アプリは記録専用のツールです。血糖値の判定・診断・治療に関する機能は提供しません。数値の解釈や治療方針については、必ず主治医の指示に従ってください。
